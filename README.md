# Trumpify

A browser-only pixel transformation GIF generator.

Upload an image, then Trumpify animates its pixels moving into the bundled Donald Trump target portrait. The finished GIF and final PNG can be downloaded.

## Setup

Upload every file to the root of a GitHub Pages repository, keeping `assets/target.png` in the same folder structure.

The app uses gif.js from jsDelivr for GIF encoding.

The bundled target portrait is the 2025 official presidential portrait of Donald Trump. The source is the White House and the image is public domain as a U.S. federal government work. Source: Wikimedia Commons.
